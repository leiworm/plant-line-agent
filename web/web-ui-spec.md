# Web 端规格（唯一用户入口）

> 约束：只在浏览器登录操作，不装客户端/插件，不做移动端，不做消息旁路。
> 设计目标：班组长**不用学提示词**，10 秒内看清本班现状。

## 1. 页面清单

| 页面 | 路由 | 内容 | 优先级 |
|---|---|---|---|
| 登录 | `/login` | 厂内 SSO / LDAP，登录后注入 `role / authorized_line_ids / shift_id` | P0 |
| 一屏总览 | `/` | 所辖线体红黄绿卡片、本班三项 KPI、未闭环异常数、最后更新时间 | P0 |
| 问答 | `/ask` | 对话区 + 快捷问题按钮 + 证据展开 | P0 |
| 异常中心 | `/events` | 异常卡片列表、筛选（级别/线体/状态）、详情与原始记录链接 | P0 |
| 交接班 | `/handover` | 草稿编辑、必填项校验、确认归档、历史查询 | P1 |
| 后台 | `/admin` | 口径版本、线体授权、订阅规则、知识库、审计查询 | P1 |

## 2. 一屏总览（最重要的一页）

```
┌─────────────────────────────────────────────────────────────┐
│  D 班 · 3 号线        最后更新 22:30:00  ● 数据正常           │
├──────────────┬──────────────┬──────────────┬────────────────┤
│ UPH  412 ⓘ   │ NTF  1.8% ⓘ  │ Retest 3.2%ⓘ│ 达成率 96% ⓘ   │
│ 目标 430     │ 目标 ≤2.0%   │ 目标 ≤3.5%  │ 工单 WO-123    │
├──────────────┴──────────────┴──────────────┴────────────────┤
│ 🔴 未闭环异常 2   🟡 提示 3                                   │
│  · 22:14  L03-ST-07  停机 E102  已 16 min    [查看] [处置]    │
├─────────────────────────────────────────────────────────────┤
│  [本线现在怎么样] [KPI 与上一班对比] [异常清单] [写交接班]      │
└─────────────────────────────────────────────────────────────┘
```

- ⓘ = 点击展开证据：`source` / `timestamp` / `metric_version` / 监控系统原始记录链接。
- 任一数据块不可用 → 该块显示「数据源不可用，最后更新 xx」，**不留空、不显示数值**。
- 常开看板页：建议工位机浏览器固定此页，配合浏览器通知承载站内告警（已接受「离屏即失联」）。

## 3. 问答区

**快捷问题按钮（P0，MVP 主要交互）**

| 按钮 | 路由 |
|---|---|
| 本线现在怎么样 | `workflow.line-snapshot` |
| KPI 与上一班对比 | `workflow.kpi-qa` |
| 还有哪些异常没闭环 | `mcp-events.get_active_anomalies` |
| 写交接班 | `agent.shift-review` |

**自由文本框**：支持厂内简称（由 `plant-terms` 映射）；解析不了时列出候选让用户点选，不猜。

**回答呈现**

1. 先结论，再明细，最后「数据说明」折叠区；
2. 每个数字带 ⓘ 证据标记，可点开原始记录；
3. 归因类回答固定四段式（可能原因 / 证据 / 建议 / 不确定项）；
4. 回答底部显示 `trace_id`，便于报障时定位；
5. 不属于可回答范围的问题 → 说明范围并给出快捷按钮，不闲聊。

## 4. 异常卡片与站内推送

- 传输：WebSocket 为主、SSE 兜底；断线重连按 `last_event_id` 回放。
- 卡片由规则引擎生成（不经 LLM）：线体 / 设备 / 事件码 / 起止 / 持续 / 等级 / 原始记录链接。
- 异步补一句解释，失败时不影响卡片展示。
- 去重（60 s 同事件同状态）、节流（同线同码 5 分钟 1 张新卡，其余合并计数）。
- 一期卡片**只读**：可在本系统内记录处置备注与状态（P1，人工确认 + 审计），不回写监控系统。
- 无外部通知：页面显式提示「关闭浏览器后将收不到新告警」。

## 5. 交接班页

- 草稿按 `shift-handover-format` 渲染，可编辑、可补录；
- 必填项缺失时「确认归档」按钮禁用，并高亮缺失项；
- 归档后只读，修订生成新版本；
- 按线体 / 班次 / 日期查历史；
- 归档动作写审计（确认人、时间、diff）。

## 6. 后台

| 功能 | 说明 |
|---|---|
| 口径版本 | 查看/新增版本，展示 diff、生效时间、审批人；与 `kpi-glossary` 双向核对 |
| 线体授权 | 角色 → 线体矩阵；默认拒绝 |
| 事件规则 | 分级映射、去重窗口、节流阈值、未映射事件码清单 |
| 知识库 | SOP / 历史案例的上传、出处标注、失效标记 |
| 术语表 | 黑话 → 标准 ID，含「未识别术语」日志 |
| 审计查询 | 按 trace_id / 用户 / 时间 / 工具查问答与调用记录 |

## 7. 非功能与适配

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome / Edge 近两个大版本；无插件 |
| 分辨率 | 工位机 1920×1080、平板横屏；字号与按钮适配触摸 |
| 首屏 | ≤ 3 s；总览刷新间隔可配（默认 10 s） |
| 状态可视 | 数据正常 / 滞后 / 不可用 三态，颜色 + 文字双编码（不只靠颜色） |
| 权限展示 | 只展示授权线体；越权请求给明确提示，不给空白页 |
| 降级 | 模型不可用时，总览与异常卡片照常工作，仅问答区提示不可用 |
| 安全 | 全站 HTTPS（厂内证书）、会话超时、操作留痕、无外网资源（不引 CDN） |

## 8. 明确不做

移动端 App · 企微/钉钉/短信/邮件推送 · 浏览器插件 · 3D 产线动画 · 大屏炫酷可视化（以可读性优先） · 任何设备控制按钮。
